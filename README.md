# Clasificador de mensajes de commit con IA

## Descripción

Este proyecto hace parte de la formación del SENA en Implementación de Soluciones de Inteligencia Artificial. La idea es crear una aplicación que clasifique mensajes de commit usando inteligencia artificial.

## Integrantes

- Dilan Guzmán
- Brigith León
- Juan Jara

## Categorías de clasificación

- `feat`: nueva funcionalidad.
- `fix`: corrección de errores.
- `docs`: documentación.
- `test`: pruebas.
- `chore`: tareas de mantenimiento.
- `refactor`: mejora del código sin cambiar su funcionamiento.

## Tecnologías del proyecto

- Python y FastAPI
- Ollama
- PostgreSQL
- Docker
- GitHub Actions
